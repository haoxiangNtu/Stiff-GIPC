# 优化路线图(2026-08-11,基于 A800 实测成本结构)

基准场景:foldshirt 4-env merged 回放,1551 帧,宿主通道 410s(263ms/帧)。
相位分解(设备 globaltimer 打点,STIFF_GRAPH_PHASE_TIME,416.8s 设备时间):

| 相位 | 时间 | 占比 |
|---|---|---|
| PCG(线性求解) | 237.1s | **56.9%** |
| — 其中 precond 应用(MAS) | 112.3s | **27%(全仿真)** |
| — 其中 SpMV | 34.1s | 8% |
| — 其中 mix1/mix2 | 31.0s | 7% |

优化原则:每个候选项对照它作用的相位占比 = 收益天花板(Amdahl)。

## 已立项(按执行序)

### 1. MAS 预条件应用降精度(fp32)
- 靶区:全仿真 27%,理论上限 ~13%(带宽减半)。
- 依据:预条件本身是近似算子,fp32 应用不改变 SPD 性,数学安全;
  比全混合精度 PCG 风险低一个量级。
- 对照实测(2026-08-11,对角替代 MAS,两轮):
  r0 = 501s/321.9ms/newton 10881,r1 = 401s/257.1ms/newton 10088;
  MAS 基线 410-411s/263ms/newton 8846-8850(极紧致)。
  解读:对角**每迭代便宜 ~13%**(r1 是本场景史上最低帧均值),但
  Newton 确定性 +14~23% 且轨迹方差巨大——净账高方差平手偏负。
  结论不变但论证更强:**MAS 的收敛 + fp32 降本的应用 = 两头通吃**;
  对角不是替代品,但它证明了 precond 应用降本能兑换成真实墙钟。

### 2. α 配方 research 档(实测 −16% Newton)
- 靶区:横切全部相位(Newton 数乘数)。
- 前置:穿透审计基建(证明放宽 CCD 钳制无穿透逃逸)。
- 合流:cap=50 饥饿帧(每轨迹 16–25 个,占总 Newton ~12%)本质是
  CCD 钳制下的"长征帧",research 档同时缓解。

### 3. 多环境掩码早退
- 靶区:GH 22% + LS 19.9% + PCG 部分(收敛 env 的陪跑)。
- 依据:P3a 探针实测各 env 在不同 k 收敛,当前循环按最难 env 退出。
- 基建:d_point_to_group / per-env 能量分解(S3)/ per-env freeze 均已在。
- env 数越多收益越大(RL 训练主场)。

### 4. ABD per-body 12×12 块预条件
- 靶区:PCG 迭代数(prismatic 2000× 强度比的刚体病态块)。
- 依据:kick×uipc 对照案既定结论(uipc 免疫 222× 靠此);兼治稳定性。

## 候选(测后再定)

- LS 试探配对集复用:α 减半位移收缩,带保守边距复用上一集合;
  难帧几十次试探的重建可砍大半;需 CCD 安全性论证。
- fp32 SpMV + fp64 残差修正:再砍 ~4%;排在 precond 降精度之后。
- 装配通道复查:C6-z 时代"-42% 通道长度 0 墙钟收益"的结论可能被
  precond 大头掩盖,值得在 precond 降本后复测。
- dt 上探(0.02→0.025/0.033):仅非抓取临界场景;临界场景禁用
  (foldshirt-grasp-criticality 结论)。
- 预条件器场景自适应:finray 2env diag 胜 / 大批量 MAS 优;
  按 env 数×接触密度启发式选型。
