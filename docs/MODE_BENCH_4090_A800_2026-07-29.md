# merged vs isolated 基准：towel / foldshirt × 4090 / A800（2026-07-29）

被测提交 `d15ffa5`（C5 收官后）。**默认旋钮**——即出货行为，整帧图旋钮全关，
所以这里量的是用户今天实际拿到的性能，不是图化后的性能。

方法：`scripts/mode_bench.py`，每格 3 次重复，warm-up 5 帧后计时；`ms/步` 是
模拟器自身的步进耗时（不含渲染），`峰值 Newton` 是该轨迹内单帧最大牛顿迭代数。
4090 一轮独占重跑（首轮与录像并发、时序作废，已弃）；A800 全程独占。

## 结果

| 场景 / 模式 | 4090 峰值 Newton | 4090 ms/步（3 次） | A800 峰值 Newton | A800 ms/步（3 次） |
|---|---|---|---|---|
| towel / merged | 94, 94, 94 | 24.3 / 29.1 / 24.2 | 92, 94, 94 | 42.0 / 39.8 / 40.5 |
| towel / isolated | 96, 96, 98 | 23.2 / 20.9 / 21.8 | 98, 98, 78 | 32.2 / 33.1 / 27.7 |
| foldshirt / merged | 50, 50, 50 | 913 / 848 / 841 | 50, 50, 50 | 1185 / 1192（2 次有效）|
| foldshirt / isolated | 50, 50, 50 | 1461 / 1434 | 50, 50, 50 | 2113 / 2070 / 2344 |

中位数对比（isolated 相对 merged）：

| 场景 | 4090 | A800 |
|---|---|---|
| towel | **-13%**（24.3→21.8） | **-22%**（40.5→32.2） |
| foldshirt | **+69%**（848→1434） | **+74%**（1185→2070） |

## 两条结构规律

**1. 布料独场景 isolated 更快，机械臂多环境场景 isolated 更慢。** 方向在两个
架构上一致，幅度也接近（towel -13%/-22%，foldshirt +69%/+74%），所以这是算法
性质而非某台机器的噪声。机制：towel 是单一大布料，per-env 的 absolute dHat 让
接触带更窄、且不触 buffer cap；foldshirt 是 4 环境 × (ABD 抓手 + 布料)，per-env
树把一次大发射拆成多次小发射，kernel 启动与树构建的固定开销吃掉了收益。

**2. 峰值 Newton 跨架构逐一对齐**（towel 94 vs 94、foldshirt 50 vs 50），说明
求解器的数值行为与 GPU 架构无关——这是正确性的旁证，也复现了 v0.8.6 三模式
矩阵当时的同一发现。foldshirt 的 50 是脚本设定的迭代 cap，不是自然收敛值。

选型建议：**布料/软体为主选 isolated**（更快且带隔离承诺）；**多环境机械臂
replay 选 merged**（约 1.7 倍差距，除非确实需要隔离保证）。

## 整帧图资格（实测，决定上面的数字怎么读）

以 `STIFF_FRAME_GRAPH_DIAG=1` 探测：

- **towel：合格**——普通 `step()` 下可进整帧条件图。
- **foldshirt：不合格**，理由 `ABD bodies are not yet device-conditional`。ABD
  场景的整帧图被刻意限定在 episode / GPU-native RL API 内（`prepare_gpu_rl`），
  普通 `step()` 走已审计的两图事务路径。

所以上表的 foldshirt 数字反映的是两图事务路径，与整帧图无关。

## 正确性验证（录像）

`scripts/record_demo.py`（新增）：headless 模拟 + matplotlib Agg 渲染 + ffmpeg
编码，两台机器通用，不需要显示器。录的是 towel 配方本身的抛落姿态（倾斜
~75°、~0.3 m 落下），因为它同时考验自碰撞、摩擦与弯曲。

- `towel_merged.mp4` / `towel_isolated.mp4`（各 160 帧）：布料边缘先着地 → 折叠
  → 贴地静置，全程有限值，Newton 收敛至 1-2。第 120 帧两模式形态一致（贴地
  高度、褶皱走向相同），与上表"物理相同、只有速度不同"的结论互证。

## 过程中修掉的一个真 bug

`scripts/mode_bench.py` 用 `PYTHONPATH=str(ROOT)` **覆写**而非追加环境变量。
4090 无感（numpy 是系统装的），但 A800 节点的 numpy 经 PYTHONPATH 挂载 →
所有 bench 子进程 import 失败 → 12 格全 FAIL 且 wall=0.0s。已改为前置追加。
任何"解释器 site-packages 走 PYTHONPATH"的部署都会踩到，不限于本次容器。

A800 环境另缺 scipy / h5py（foldshirt 读轨迹用），已离线 wheel 补装到
`~/workspace/tools/{scipy_pkg,h5py_pkg}`，经 PYTHONPATH 引入。
