# 仿真器执行架构:一个表面、两个内核(定稿)

日期:2026-08-04 · 基线:codex/phase-cd @ a929b1c · 实测卡:A800(部署)/ RTX 4090(本地)

本文沉淀 Phase C/D + C5/C6 全部战役后的最终执行架构。每一条设计都附实测
依据;没有实测依据的表述一律标注为目标而非事实。

## 0. 一页结论

```
用户视角(Isaac 式,唯一 API 面):
  build scene → finalize() → step() ... step()                    平时
              → prepare_gpu_rl() → step() ... step() → end_gpu_rl()  训练段
                     └ 之后 step() 自动薄发射,用户无感

内核视角(两条执行通道,共享驻留地基):
  step 通道    = 宿主帧骨架 + PCG 自发射图岛 + 每帧边界事务      ← 大帧最优
  residency 通道 = 整帧图 + 设备 resizer + 多帧连发 + 段边界事务  ← 微帧最优
```

- 模式切换 = 用户在程序相位边界的**显式声明**(prepare/end),永不自动、
  永不按帧猜测。
- 大帧回放走 step:三案实测 ≥ v0.8.5(forcegrip −2~3%、beaker 每帧持平、
  finray +15%);整帧图开则倒贴 +6~14%。
- RL 微步走 residency:A800 5.0x、4090 1.34x(收益 ∝ 宿主往返延迟,是
  **平台的函数**;residency 在两台机器上均不低于宿主路径,无反例)。

## 1. 术语澄清:三个 "episode"

| 词 | 语义 | 长度由谁定 |
|---|---|---|
| prepare↔end 跨度 | **整个训练阶段**(小时级),"拓扑冻结、纯微步"的程序相位 | 用户的程序结构;Isaac 的 `prepare_sim` 同物,且 Isaac 连 end 都没有 |
| RL episode(done→reset) | 智能体轨迹 | 训练逻辑;reset 在设备侧 mask 完成(`gpu_rl_mask_reset_gate`),引擎不关心 |
| 代码中的 "episode graph" | **容量事务粒度**(warm-up 训档、headroom×2、溢出边界处理) | 引擎内政,用户零参数 |

为杀掉歧义,本文及后续文档将第三者改称 **residency span(驻留段)**。代码
标识符暂不更名(改名风险 > 收益),仅文档层统一。

## 2. 五层动态性分类(图能动什么、不能动什么)

| 层 | 内容 | 处置 | 机制 |
|---|---|---|---|
| L1 | 控制流(Newton/PCG 循环、收敛判断) | 图内动态 | 条件节点(WHILE/IF),设备判收敛 |
| L2 | 工作量(接触对实际数量) | 图内动态 | 设备计数掩码,核内按实时计数干活 |
| L3 | 发射宽度(grid 尺寸) | 图内动态 | 设备侧 grid resize(16 槽环独占,`cudaGraphKernelNodeSetGridDim`),零值跳过 |
| L4 | 拓扑(节点/边结构) | 静态 | 变了就边界重录 |
| L5 | 显存/指针 | **静态,CUDA 硬边界** | cudaMalloc 仅 CPU;一切扩容都是边界事务 |

任何"全 GPU 自治扩容"的表述都违反 L5,不存在于任何引擎(PhysX 的答案是
定死上限、超限丢接触)。

## 3. 图化分配表(什么住在哪个模式,依据是什么)

| 技术 | step | residency | 实测依据 |
|---|---|---|---|
| PCG 自发射图(K=8 设备收敛) | ✅ 默认 | ✅(录进整帧图) | 每帧数万微核发射,唯一图化收益为正的部分;v0.8.5 起双版默认开 |
| 整帧图(装配/积分/接触全录) | ❌ 永不 | ✅ 核心 | 大帧倒贴 +6~14%(发射间隙实测 0.06–0.1µs,图无钱可省,还付 memset 慢核+档位宽税);微帧省 τ 的唯一手段 |
| 设备 resizer + L2 掩码 + 零值跳过 | — | ✅ | 原子长龙 -27%;零 pad 数学中性(独立核,防 codegen 扰动原子序) |
| 宿主精确宽度发射 | ✅ 本体 | ❌ | 接触形状逐迭代变,宿主发射免费且精确 |
| 容量事务 | 每帧边界,headroom=1 | 段边界,headroom≥2 + warm-up 训档 | C6-p:headroom 2→1 是大帧 pad 税主源;残留段 floor 2 保重放 |
| 多帧批量发射 | — | ✅ | full-dynamic 合入;CPU 投递频率 ÷N |

发射经济学一句话:**串行化贵、宽度免费**——痛苦 ∝ 发射次数×延迟÷单核
计算量。PCG(几万次微核)图化;装配(千次百微秒核)不图化;接触(形状
易变)宿主精确发射。

## 4. 通道选择判据(用户视角)

判据 = 每步宿主固定开销 τ ÷ 每帧计算量 T:

| 场景 | 通道 | 原因 |
|---|---|---|
| 大帧回放/重放(>50ms/帧) | step | τ/T < 1%,重事务免费换来精确宽度+最强溢出裁决 |
| RL 训练内环(几 ms/帧 × 数千步) | residency | τ/T 10–80%;A800 5x |
| 帧间改场景/加物体 | step | residency 段拓扑冻结(L4/L5) |
| 逐帧调试/裁决 | step | residency 的卖点就是不看每帧 |

τ 是**平台属性**:A800 集群 ~15ms/步、桌面 4090 ~1ms/步。residency 的
价值在部署集群上;桌面上不亏但不惊艳(1.34x)。

**第二判据(2026-08-04 真实轨迹实验补充):容量平稳性**。residency 段要求
接触规模平稳(稳态 RL 微步);接触逐帧升级的操作轨迹(foldshirt 抓握)会
立刻击穿训练档——接触类(triplet)容量档只能通过 step 事务的 OVF-required
反馈生长,单帧观测训练看不到它,而再捕获的观测训练还会覆盖已生长的类档
(赋值非取 max,已定位待修)。实验:foldshirt 第 15 帧 auto-prepare 后
25/25 帧 OVF_TRIPLETS 失败(fail-closed 成立:失败帧不提交,物理停在上个
好帧;首次冒烟的"2.2x 加速"即 25 帧空转假象,被健康审计抓获)。结论:
**真实大帧操作轨迹必须走 step 通道**——不是慢一点的问题,是驻留合同
(容量冻结)与其工作负载(容量升级)矛盾。其性能上界代理=step 整帧图开
=已测 +6~14% 慢,方向一致。

## 5. 边界协议(切换那一刻发生什么)

**prepare_gpu_rl()**(一次,秒级):
1. warm-up 帧在代表性接触下实测各轴峰值 → pow2 档位 + headroom≥2;
2. 录整帧图(参考:D4 场景 1089 节点、h2d=0/d2h=0),武装设备 resizer;
3. 拓扑/显存冻结,交出设备端 action/obs 缓冲。

**段内(日常,99.9%+ 的步)**:
- CPU 仅入队(微秒,不等待/不回读/不裁决);GPU 重放图、写 obs、设备侧
  mask reset done 的 env。

**溢出事件(稀有;foldshirt 1551 帧审计 overflow=0)**:
- 设备写 OVF 位+实际需求,拒绝提交坏帧(状态停在上个好帧);后续已入队
  重放看 OVF 位条件空转排空;
- CPU 在边界/异步 poll 看到 → cudaMalloc 扩档 → 重录 → 检查点续跑。
- 代价毫秒~秒级,轨迹不丢、物理不错(对照 PhysX:零代价但静默丢接触)。

**end_gpu_rl()**:解冻编辑,step() 回宿主骨架。Isaac 无此能力(改拓扑须
重启进程),这是我们多给的,不用可不调。

CPU 的三个层次:**在场**(python 循环+入队,每步,微秒)≠ **参与**(等待
/回读/裁决,正常轨迹为零)≠ **干预**(扩容重录,仅溢出事件)。薄发射 =
CPU 从裁决者降级为投递员,与 Isaac `gym.simulate()` 同构。

## 7. 能力补全计划(本轮实施)

1. **prepare 自含化**:tier 训练依赖 device_count_mode(),现只认
   STIFF_FRAME_GRAPH/STIFF_CONVERT_DEVICE_COUNT 环境;资格检查还要求
   C4/C6 旋钮。改为 prepare 生命周期 RAII 强制开启,用户零环境变量
   (Isaac 从不要求用户设 env)。
2. **step() 自动分流**:prepare 后 step() 路由到薄发射;状态 getter 惰性

3. **torch 零拷贝互操作**:ABI 指针包 `__cuda_array_interface__`,
   action/obs 免 .numpy() 往返。
4. 门禁回归(必须自带构建)+ 终局 fps/总时长对比实验,结果回填本文附录。

## 8. 明确不做(及其证据)

- **Persistent GPU Runtime 全量重写**:arena 耗尽仍需 CPU(同一稀有事件
  协议的更贵写法);维持 3 原型裁决门槛。
- **按帧自动切换通道**:两通道容量契约/原子序/数值包络不同,中途切换=
  换数值机器,门禁无法背书。
- **执行层继续找性能**:大帧发射间隙 0.06–0.1µs、四次收窄宽度 0 收益、
  动态改图节点收益 0——执行层无欠账,收益在算法层。
- **图内重试溢出帧**(STIFF_GRAPH_INGRAPH_RETRY 保持实验开关):改变
  grid/归约顺序,曾放大接触场景非确定性。

因迭代轮数而放大。**捕获变宽度迭代算法前,必须先确认其每轮宽度是否可收缩。**

## 附录 C:CCD 步长上限调优(α 战役,2026-08-07)

重帧成本 = Newton 数 × ~25ms,而 α(CCD 步长上限)普查显示三分天下:ground
34.6% / CFL 32.8% / refined(ACCD 实算)32.4%,其中 CFL 在 22.6% 的迭代把 α
压到 ACCD 认证值之下(中位 1.48x)。CFL 单因子实际扮演三个角色,安全性各异:

| 角色 | 处置 | 理由 |
|---|---|---|
| 上限(swept-BVH 膨胀护栏) | `STIFF_CCD_CFL_FACTOR` 可调 | 放宽后 α 仍被认证值封顶 |
| 下限(覆盖极小 refined) | 钉死 0.5 | 未认证位移,放大有薄布隧穿风险且无 fail-fast 可抓 |
| refined 触发阈值 | 钉死原值 | swept ACCD 是远处快速接近对的唯一认证者 |

**推荐配置(仅重接触场景)**:`STIFF_CCD_SLACK_M=0.9 STIFF_CCD_CFL_FACTOR=1.0`
→ Newton −7.9%(5 批配对全负)、墙钟 −3~4%(A800 fs4-4env 全轨迹)。cap>1.0
在安全语义下惰性(触发钉死后上限已完全放开)。轻接触场景(forcegrip/beaker)
零收益或小亏,勿开。默认全关;门禁 21/21 绿、金锚逐位不变。

测量方法定版:全轨迹 Newton 总数为主判据(重复性 ±1%,抗混沌),60 帧窗墙钟
噪声 ±10pp 不可用于 <10pp 效应;凡裁决必须带同配置 A/A 对照。

## 附录 D:最快整体配置总表(2026-08-09 定稿,全项 A/A 校准背书)

两层决策:通道按 regime,配置按场景。

**通道**:大帧 = step 宿主图关(图开 +10~15%,弥散成本无单一病灶,已四方向
排除);RL 稳态微步 = residency(A800 5x);接触升级轨迹禁止 prepare(容量
平稳性判据);需尾延迟可预测时图开可接受(方差 ±8% vs 宿主 ±21%)。

**场景配置**:重接触 = MAS + `STIFF_CCD_SLACK_M=0.9 STIFF_CCD_CFL_FACTOR=1.0`
(Newton −7.9%,墙钟 −3~4%,全程 ACCD 认证内);轻接触 = α 配方关(beaker
零、forcegrip +4% 真回归),预条件器按场景;episode 通道 α 配方未验证,暂关。

**钉死参数**(双向实验完备,勿动):headroom=1、档梯 2 的幂、PCG K=8、CFL
下限与 swept 触发 = 上游原值(安全机制,放大有隧穿风险且无 fail-fast 可抓)。

**测量法**(裁决前置条件):全轨迹 Newton 总数为主判据(±1%),60 帧窗墙钟
±10pp 不可裁 <10pp 效应,凡裁决必须带同配置 A/A 对照。

**剩余靶点**(期望值序):MAS 内参(apply 占 PCG body 65%,levelnum≤6 未扫)、
α 自动门控(按接触量自适应开关)、kappa→Newton 数扫描、穿透审计(解锁研究值
α −16%N 的前置)。
