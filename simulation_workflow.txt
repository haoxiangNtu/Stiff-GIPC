一、项目概述
============
StiffGIPC 是一个基于 GPU 的 IPC (Incremental Potential Contact) 仿真框架，
支持软体 (FEM)、刚体 (ABD)、布料及其混合耦合仿真。
论文: "StiffGIPC: Advancing GPU IPC for Stiff Affine-Deformable Simulation"
ACM Transactions on Graphics, 2025

二、编译与运行
==============

  依赖安装 (Ubuntu):
    sudo apt install libglew-dev freeglut3-dev libeigen3-dev nlohmann-json3-dev libtbb-dev

  Release 编译:
    cd build
    cmake .. -DCMAKE_BUILD_TYPE=Release
    make -j24

  Debug 编译 (RelWithDebInfo):
    cd build-debug
    cmake .. -DCMAKE_BUILD_TYPE=RelWithDebInfo
    make -j24

  运行:
    cd build 或 build-debug
    ./gipc

  调试:
    cuda-gdb ./gipc        (可调试 CUDA kernel)
    gdb ./gipc              (只调试 CPU 端)
    或在 Cursor 中按 F5 (已配置 .vscode/launch.json)

六、牛顿迭代核心: solve_subIP() [GIPC.cu:10854]
================================================

  for k = 0 to 10000 (最大迭代次数):

    Step A: computeGradientAndHessian() [GIPC.cu:10889]
    ─────────────────────────────────────────────────────
      计算总能量的梯度 g 和 Hessian 矩阵 H
      总能量 = 惯性项 + FEM弹性能 + IPC接触势垒能 + 摩擦能
      - 惯性项: 1/(2·dt²) · M · ||x - x̃||²
      - FEM弹性能: Ψ(F) (Neo-Hookean / StVK 等)
      - IPC势垒: Σ b(d(x)) (距离势垒函数)
      - 摩擦: Σ f(x) (IPC 摩擦模型)

    Step B: 收敛判断 [GIPC.cu:10894-10910]
    ─────────────────────────────────────────
      distToOpt = ||moveDir||  (梯度范数)
      if distToOpt < sqrt(threshold² · bboxDiagSize² · dt²)
        → 收敛, break

    Step C: calculateMovingDirection() [GIPC.cu:10914]
    ────────────────────────────────────────────────────
      用 PCG (预条件共轭梯度法) 求解:
        H · dx = -g
      得到搜索方向 dx
      预条件器: MAS (Multilevel Additive Schwarz) 预条件器
        - 使用 METIS 图分区
        - 多级加性 Schwarz 域分解

    Step D: CCD 安全步长计算 [GIPC.cu:10919-10951]
    ─────────────────────────────────────────────────
      ① ground_largestFeasibleStepSize()  地面 CCD
      ② self_largestFeasibleStepSize()    自碰撞 CCD
      ③ buildBVH_FULLCCD() + buildFullCP() 全局 CCD
      ④ CFL 条件: alpha_CFL = sqrt(dHat) / maxSpeed * 0.5
      最终步长 alpha = min(以上所有约束)

    Step E: lineSearch() [GIPC.cu:10956]
    ──────────────────────────────────────
      沿 dx 方向做线搜索 (Armijo 回溯)
      确保总能量严格下降

    Step F: postLineSearch() [GIPC.cu:10959]
    ──────────────────────────────────────────
      更新顶点位置
      重建 BVH: buildBVH()
      重建碰撞对: buildCP()

  输出: 牛顿迭代次数 k

七、关键数据结构
================

  tetMesh (CPU 端):
    - vertexes[]       顶点坐标 (double3)
    - tetrahedras[]    四面体索引 (uint4)
    - triangles[]      三角形索引 (uint3, 用于布料)
    - surface[]        表面三角形
    - surfEdges[]      表面边
    - surfVerts[]      表面顶点
    - masses[]         顶点质量
    - velocities[]     顶点速度
    - DM_inverse[]     参考构型变形梯度逆
    - boundaryTypies[] 边界类型 (0=自由, 1=固定)

  d_tetMesh (GPU 端):
    tetMesh 的 GPU 镜像, 存在 CUDA device memory 中

  ipc (GIPC 求解器):
    - _vertexes        GPU 顶点指针
    - _faces/_edges    GPU 表面面/边
    - bvh_f/bvh_e      BVH 树 (面/边)
    - _collisonPairs   碰撞对
    - pcg_data         PCG 求解器数据
    - Kappa            接触刚度
    - dHat             接触距离阈值
    - IPC_dt           时间步长
